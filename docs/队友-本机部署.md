# 在自己电脑上跑起来（队友版）

三种情况选一种，不要混着来。

---

## 情况 A：只想用手机测 App，不想动代码

**最简单。你电脑什么都不用装。**

1. 拿到 APK（群里发，或 `交付/` 目录里最新的那个）
2. 手机上**先卸载旧的「应变」**（签名不同，不卸载装不上）
3. 装上，打开
4. 手机和**跑后端那台电脑**连同一个 Wi-Fi
5. 如果显示「出了点问题」→ 点【自动寻找服务器】

> 后端在哪台电脑上，就由那台电脑负责；你只当客户端。

---

## 情况 B：自己跑后端（要改代码 / 要独立数据）

### 1. 拉代码

```bash
git clone https://github.com/chenzhuoyu333-dot/yingbian.git
cd yingbian
git pull            # 每次开工前都拉一次，避免和老代码打架
```

### 2. 装依赖（Python 3.11+）

```bash
python -m pip install -r requirements.txt
```

### 3. 配 key（**必须，且不进仓库**）

```bash
copy .env.example .env      # Windows
cp .env.example .env        # macOS / Linux
```

打开 `.env` 填两个值：

```
AMAP_KEY=你申请的高德 Web 服务 Key     ← 不填就搜不到地点，生成会失败
LLM_API_KEY=你的 DeepSeek Key          ← 不填会退回规则解析（界面会标注）
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

`.env` 已经在 `.gitignore` 里，**永远不会被提交**。想共用 key 就私聊发，别写进代码。

### 4. 启动后端

```bash
python -m uvicorn server.app:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`：
- 看到一个紫色标题的**状态页** = 起来了
- 状态页上会显示「手机该填的地址」，也就是你电脑的局域网 IP

### 5. 手机连上

手机和电脑连**同一个 Wi-Fi**，App 里点【自动寻找服务器】，它会自己扫到你的电脑。

也可以手动填：状态页上那个 `http://10.xxx.x.x:8000`。

### 6. 想自己打 APK（可选）

需要 **Android Studio / Android SDK / JDK 21**。第一次用 Android Studio 打开 `android/` 目录，它会自动生成 `local.properties`（这个文件不在仓库里，因为里面是本机 SDK 路径）。

```bash
cd android
gradlew.bat assembleLanDebug -PbaseUrl=http://你电脑的IP:8000
```

产物：`android/app/build/outputs/apk/lan/debug/app-lan-debug.apk`

> 没有 Android SDK 就别折腾了，直接用别人打好的 APK。改代码不等于必须自己打包 —— 后端改完重启 uvicorn 就生效。

## 情况 C：两台电脑都在用

**谁跑后端，谁的电脑就是服务器。** App 的「自动寻找」会找到当前网段上跑着的那个，所以不用担心 IP。

但有一件事必须知道：

> **数据不共享。** `data/plans/`（用户生成的行程）是本地文件，也被 gitignore 了。
> 你的电脑上生成的行程，我这边看不到，反之亦然。

所以：

| 场景 | 怎么办 |
|---|---|
| 各改各的代码 | 没问题，用 git 同步 |
| 演示 / 录视频 | **统一用一台电脑跑后端**，另一台只装 APK |
| 要看到对方的行程 | 让对方在 App 里导出，或临时用同一台后端 |

## 常见故障对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 装不上，提示签名不一致 | 两个包签名不同 | 卸载旧版再装 |
| 打开后「出了点问题」 | 后端没开 / 地址变了 / 不同 Wi-Fi | 点【自动寻找服务器】；仍失败就看下一条 |
| 自动寻找也失败 | 手机和电脑不在同一网段 | 手机浏览器打开 `http://<电脑IP>:8000`，打不开就是网络问题 |
| 生成行程失败 | 缺 `AMAP_KEY` | 检查 `.env`，重启后端 |
| 界面显示「规则解析」 | 缺 `LLM_API_KEY` | 同上；功能降级但可用 |
| 首页列表是空的 | 你的后端还没有行程 | 点 + 新建一份 |
| `gradlew` 报 SDK 找不到 | 没有 `local.properties` | 用 Android Studio 打开一次 `android/` 自动生成 |

---

## 别做的事

- **别把 `.env` 提交**（有 key）
- **别改 `.gitignore` 里 `data/plans/` 的规则**（运行时数据不该进库）
- **别两个人同时改同一个 Kotlin 文件后各自 push**（界面文件冲突最多）

分文件干活的建议：

```
交通 / 住宿 / 打卡   → poi.py, route_plan, location.py
界面 / 生成 / 巡检   → Screens.kt, App.kt, patrol.py, generate.py
```
